## The problem

Staff on location had to interpret a category chart themselves to create tickets. The result: wrong categories and missing details.

## The approach

I built a decision tree in Zoho Desk that asks questions and creates the complete ticket through the API. The structure is based on an analysis of 2,251 real tickets. The platform cannot split text or calculate, so I worked around that with API patterns.

## The result

The Administration category is fully built and tested, including automatic calculations. The next category is designed.
