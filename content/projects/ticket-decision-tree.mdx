## The problem

Staff on location create tickets for everything that needs attention in a building. To pick the right category they had to read a category chart and interpret it themselves. The result: wrong categories and missing details.

## The approach

### Questions instead of a chart

A decision tree in Zoho Desk, built with Guided Conversations, asks the questions. Each answer decides the next question. At the end the tree creates the complete ticket through the API, with the right category and all the details that category needs.

### Based on real tickets

The structure follows from an analysis of 2,251 real tickets. The categories and questions therefore follow what staff actually report, instead of what a chart assumes.

### Calculations inside the conversation

Some tickets need a calculated value, and some answers have to be split into separate fields. Guided Conversations can do neither. Both are handled with API calls from inside the tree, so the staff member does not notice the limitation and the ticket arrives with the calculation already done.

### Access through OAuth

The tree talks to the Zoho Desk API through OAuth, so it only has the rights it needs to create tickets.
