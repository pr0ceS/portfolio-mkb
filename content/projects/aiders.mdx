## The problem

Webshops get a lot of "where is my order" emails. This is worst for dropshippers, because their delivery times are long.

Slow answers lead to angry customers and bad reviews. They also lead to chargebacks, where a customer asks the bank for the money back. With enough chargebacks a shop can lose its payment provider, and then it cannot sell at all.

I ran into this with my own webshops. That is why I built Aiders.

## The approach

Aiders is a SaaS product that reads incoming customer service emails and answers them by itself, in the language of the customer.

The core is a multi-agent system written in Python with LangGraph. I set it up as a swarm, which means several specialised agents hand a conversation over to each other instead of one agent trying to do everything.

The answers have to be true. For that I use RAG, short for retrieval-augmented generation: before the agent writes, it looks up the relevant shop and order data and bases its answer on that. The data is stored in Qdrant, a vector database. This keeps the agent from making things up.

Emails are handled in the background. Celery workers and Redis take care of that, so a busy inbox does not slow anything down. The API is written in Python with FastAPI. Supabase provides the PostgreSQL database and the login. Everything runs in Docker containers on Fly.io.

Merchants get a dashboard built with Next.js. There is also an affiliate and partner system.

## The result

Aiders passed the Shopify review and is live in the Shopify App Store.

The project covers the full path of an AI agent: the architecture, the build, running it in production and getting it through an app store review.
