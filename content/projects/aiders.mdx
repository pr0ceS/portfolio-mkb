## The problem

Webshops get a lot of "where is my order" emails. This is worst for dropshippers, because their delivery times are long.

Slow answers lead to angry customers and bad reviews. They also lead to chargebacks, where a customer asks the bank for the money back. With enough chargebacks a shop can lose its payment provider, and then it cannot sell at all.

Aiders grew out of exactly this situation at my own webshops, where answering these emails took more time than anything else.

## The approach

Aiders is a SaaS product that reads incoming customer service emails and answers them by itself, in the language of the customer.

### Several agents instead of one

The core is a multi-agent system written in Python with LangGraph. It is set up as a swarm: several specialised agents hand a conversation over to each other, instead of one agent trying to do everything. Each agent has a smaller job, which makes its answers easier to check and to improve.

### Answers based on real data

An answer about an order has to be true. Before an agent writes, it looks up the relevant shop and order data and bases its answer on that. This is called RAG, short for retrieval-augmented generation. The data is stored in Qdrant, a vector database, which finds texts by meaning instead of by exact words. This keeps the agent from making things up.

### Built for a busy inbox

Emails are handled in the background by Celery workers, with Redis as the queue. A full inbox therefore does not slow down the rest of the app. The API is written in Python with FastAPI. Supabase provides the PostgreSQL database and the login. Everything runs in Docker containers on Fly.io.

### For the merchant

Merchants manage everything from a dashboard built with Next.js. There is also an affiliate and partner system, for people who bring in new shops.

## The result

Aiders passed the Shopify review and is live in the Shopify App Store. Any Shopify merchant can install it from there.

The project covers the whole path of an AI agent: the architecture, the build, running it in production and getting it through an app store review.
