## The problem

The link that sends deals to Exact Online as subscriptions returned vague errors. Nobody could find the cause.

## The approach

I added full logging and diagnostics without changing the logic: every record, request and response per API call, and every error line instead of only the first.

## The result

Errors can now be traced to the exact cause, for example a contact person who is registered in a different administration.
